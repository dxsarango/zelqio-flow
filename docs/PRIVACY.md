# Privacy and local storage

Sin telemetría, analytics, cuentas propias, servidor cloud, tracking ID ni crash report automático. Almacenamiento en host del daemon (local respecto a Paseo, incluso si cliente remoto). Proveedores cloud y GitHub reciben datos necesarios para tareas autorizadas conforme a sus políticas; no prometer que todo procesamiento de IA es local.

Datos mínimos: settings/roles/autorizar proyectos (hasta que usuario los elimine), run/task/agent IDs, branches/SHAs/estado/evidencias resumidas (vida de tarea), journal de operaciones (hasta reconciliar + retención), caché de cuotas con timestamp/reset. Retención propuesta configurable: routing 30 días, Git journal completado 90 días; operaciones activas no purgar. Métricas agregadas opcionales, local exclusivamente. No copiar chats, prompts completos, código, credenciales, archivos secretos ni identificadores de tracking. Los logs deben redactar errores de herramientas (pueden incluir URLs o datos sensibles). Exportación manual revisable y saneada; ninguna subida automática. Desinstalación preserva repositorios y perfiles, informa datos propios y ofrece limpieza explícita segura. Migraciones versionadas, backup local y manejo de corrupción; elección de tecnología tras G0.
