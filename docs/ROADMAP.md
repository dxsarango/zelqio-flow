# Roadmap

| Nivel | Hitos | Condición |
|---|---|---|
| Foundation | G0 condicionado y S01 (G1) | Windows y Paseo 0.17.4, operación local supervisada y validación de cada capacidad habilitada. |
| Advanced Orchestration | S02–S08, con G2–G8 | Routing, roles, integración nativa, concurrencia, relevo, Git y Smart Review. Cada efecto se habilita tras validar la capacidad, la plataforma y el destino. |
| Complete MVP | S09–S10, con G9 y G10 | Cumplir todos los FR/NFR originales, cerrar las comprobaciones pendientes y validar compatibilidad, seguridad, privacidad y ciclo de vida antes de distribución pública. |

- S00 — Definition & Feasibility: 9 tareas; gate G0 antes de siguiente fase.
- S01 — Foundation: 6 tareas; gate G1 antes de siguiente fase.
- S02 — Providers & Roles: 5 tareas; gate G2 antes de siguiente fase.
- S03 — Smart Router: 5 tareas; gate G3 antes de siguiente fase.
- S04 — Native Integration: 4 tareas; gate G4 antes de siguiente fase.
- S05 — Agent Orchestration: 6 tareas; gate G5 antes de siguiente fase.
- S06 — Git Coordinator: 6 tareas; gate G6 antes de siguiente fase.
- S07 — Work Modes: 7 tareas; gate G7 antes de siguiente fase.
- S08 — Validation & Delivery: 5 tareas; gate G8 antes de siguiente fase.
- S09 — Hardening: 6 tareas; gate G9 antes de siguiente fase.
- S10 — Public Release: 4 tareas; gate G10 antes de siguiente fase.

Se conservan las fases y los IDs en [PLAN.md](../planning/PLAN.md). La [matriz de validación](VALIDATION-BACKLOG.md) asigna pendientes a las fases existentes. G0 autoriza Foundation. G9, G10 y la autorización de distribución siguen siendo requisitos para publicar el plugin.
